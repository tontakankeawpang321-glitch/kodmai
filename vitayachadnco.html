# ฟิสิกส์ (แรง การเคลื่อนที่ พลังงาน)

  • • กฎนิวตัน: $F = ma$ (แรง = มวล x ความเร่ง)
  • • การเคลื่อนที่: $v = u + at$ และ $s = vt$
  • • พลังงานศักย์: $E_p = mgh$ (ขึ้นกับมวลและความสูง)
  • • พลังงานจลน์: $E_k = \frac{1}{2}mv^2$ (ขึ้นกับมวลและความเร็ว)
  • • ไฟฟ้า: กฎของโอห์ม $V = IR$ และกำลังไฟฟ้า $P = VI$

# เคมี (สารและการเปลี่ยนแปลง)

  • • ค่า pH: ต่ำกว่า 7 เป็นกรด, เท่ากับ 7 เป็นกลาง, สูงกว่า 7 เป็นเบส
  • • ปฏิกิริยากรด-เบส: กรด + เบส $\rightarrow$ เกลือ + น้ำ
  • • ธาตุสำคัญ: ไฮโดรเจน ($H$) มีเลขอะตอม 1, โซเดียมคลอไรด์ ($NaCl$) คือเกลือแกง
  • • การเปลี่ยนแปลง: กายภาพ (ละลายน้ำ, เปลี่ยนสถานะ), เคมี (เกิดสารใหม่, เปลี่ยนสี/กลิ่น)

# ชีววิทยา (เซลล์และระบบร่างกาย)

  • • เซลล์พืช vs สัตว์: พืชมีผนังเซลล์และคลอโรพลาสต์
  • • พันธุกรรม: DNA ทำหน้าที่เก็บสารพันธุกรรม
  • • การสังเคราะห์แสง: เกิดในคลอโรพลาสต์ ใช้แสง, น้ำ และ $CO_2$
  • • ระบบอวัยวะ: หัวใจ (สูบฉีดเลือด), ไต (กรองของเสีย), ตับ (กำจัดสารพิษ)
