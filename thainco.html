# หลักภาษา (การสร้างคำ)

  • • คำประสม: นำคำมูล 2 คำขึ้นไปที่มีความหมายต่างกันมารวมกัน เกิดความหมายใหม่ (เช่น แม่น้ำ, ตู้เย็น, ลูกน้อง)
  • • คำซ้อน: นำคำที่มีความหมายเหมือนกัน คล้ายกัน หรือตรงข้ามกันมาซ้อนกัน (เช่น ใหญ่โต, ถ้วยชาม, สูงต่ำ)
  • • คำสมาส: นำคำบาลี-สันสกฤตมารวมกัน อ่านออกเสียงสระต่อเนื่อง และแปลความหมายจากหลังไปหน้า (เช่น ประวัติศาสตร์, อุบัติเหตุ)
  • • คำสนธิ: สมาสแบบมีการเชื่อมเสียงกลืนกัน (เช่น วิทยา + อาลัย = วิทยาลัย, ธนู + อาคม = ธันวาคม)

# การใช้ภาษา (ชนิดของประโยค)

  • • ประโยคความเดียว: มีใจความสำคัญเดียว มีประธานและกริยาหลักเพียงชุดเดียว (เช่น หลานสาวตัวน้อยเดินไปโรงเรียน)
  • • ประโยคความรวม: ประโยคความเดียว 2 ประโยคขึ้นไปเชื่อมกันด้วยคำสันธาน (และ, แต่, หรือ, จึง)
  • • ประโยคความซ้อน: มีประโยคหลักและประโยคย่อยซ้อนกันอยู่ มักมีคำเชื่อม "ที่, ซึ่ง, อัน, ว่า, ให้"

# สำนวน สุภาษิต คำพังเพย

  • • กงเกวียนกำเกวียน: กรรมสนองกรรม หรือเวรสนองเวร ทำอะไรไว้ก็ได้อย่างนั้น
  • • มือถือสาก ปากถือศีล: ปากบอกว่าเป็นคนดีมีศีลธรรม แต่แท้จริงแล้วกลับประพฤติชั่ว
  • • แกว่งเท้าหาเสี้ยน: หาเรื่องเดือดร้อนใส่ตัวทั้งที่อยู่ดีๆ ก็ไม่เป็นไร
  • • ชักหน้าไม่ถึงหลัง: รายได้ไม่พอกับรายจ่าย
  • • ตำน้ำพริกละลายแม่น้ำ: ลงทุนไปมากแต่ได้ผลประโยชน์กลับมาน้อย ไม่คุ้มค่า
