# พีชคณิต และ การแก้สมการ

  • • การแก้สมการเชิงเส้น: ย้ายข้างตัวแปรให้อยู่ฝั่งเดียวกัน และตัวเลขอยู่อีกฝั่ง
    ตัวอย่าง: $2x + 5 = 15 \rightarrow 2x = 10 \rightarrow x = 5$
  • • กำลังสองสมบูรณ์: $(a+b)^2 = a^2 + 2ab + b^2$ และ $(a-b)^2 = a^2 - 2ab + b^2$
  • • ผลต่างกำลังสอง: $(a-b)(a+b) = a^2 - b^2$
    ตัวอย่าง: $(x-3)(x+3) = x^2 - 9$
  • • สมการกำลังสอง $ax^2+bx+c=0$: ผลบวกราก $= -b/a$, ผลคูณราก $= c/a$

# เลขยกกำลัง และ กรณฑ์ (ราก)

  • • สมบัติการคูณ/หาร: $a^m \times a^n = a^{m+n}$ และ $a^m \div a^n = a^{m-n}$
    ตัวอย่าง: $2^3 \times 2^4 = 2^7 = 128$
  • • เลขชี้กำลังเป็นศูนย์/ติดลบ: $a^0 = 1$ (เมื่อ $a \neq 0$) และ $a^{-n} = \frac{1}{a^n}$
  • • สมบัติของราก: $(\sqrt{a})^2 = a$ และ $\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}$

# เรขาคณิต และ ตรีโกณมิติ

  • • พื้นที่: สามเหลี่ยม $= \frac{1}{2} \times$ ฐาน $\times$ สูง, วงกลม $= \pi r^2$
  • • ทฤษฎีบทพีทาโกรัส: $c^2 = a^2 + b^2$ (ด้านตรงข้ามมุมฉากยาวสุด)
    เลขชุดที่พบบ่อย: 3-4-5, 5-12-13, 7-24-25
  • • ตรีโกณมิติ: $\sin 30^\circ = \frac{1}{2}$, $\cos 60^\circ = \frac{1}{2}$, $\tan 45^\circ = 1$
  • • เอกลักษณ์: $\sin^2 \theta + \cos^2 \theta = 1$ เสมอ

# สถิติ ความน่าจะเป็น และ ลำดับอนุกรม

  • • ค่ากลางข้อมูล: ค่าเฉลี่ย (Mean) = ผลรวม/จำนวน, มัธยฐาน (Median) = ค่าตรงกลาง
  • • ความน่าจะเป็น: $P(E) = \frac{n(E)}{n(S)}$ (เหตุการณ์ที่สนใจ $\div$ เหตุการณ์ทั้งหมด)
  • • อนุกรมเลขคณิต: $S_n = \frac{n}{2}(a_1 + a_n)$
  • • ผลบวก 1 ถึง n: $\frac{n(n+1)}{2}$
    ตัวอย่าง: 1+2+...+50 $= \frac{50(51)}{2} = 1275$
