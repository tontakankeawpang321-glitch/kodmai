สรุปไวยากรณ์ภาษาอังกฤษ

1. Tenses ที่ออกสอบบ่อย

• Present Simple: S + V.1 (s,es) - ใช้กับความจริง, กิจวัตรประจำวัน (คำบอกเวลา: always, usually, every day)

• Present Continuous: S + is/am/are + V.ing - ใช้กับเหตุการณ์ที่กำลังเกิด (คำบอกเวลา: now, at the moment, Listen!)

• Past Simple: S + V.2 - ใช้กับเหตุการณ์ที่จบไปแล้วในอดีต (คำบอกเวลา: yesterday, last week, ago)

• Present Perfect: S + has/have + V.3 - เกิดในอดีตดำเนินมาถึงปัจจุบัน (คำบอกเวลา: since, for, already, just, yet)

2. ประโยคเงื่อนไข (If-Clause)

• แบบที่ 1 (เป็นไปได้ในอนาคต): If + Present Simple, Future Simple
Ex. If it rains, I will stay home.

• แบบที่ 2 (สมมติตรงข้ามกับความจริงในปัจจุบัน): If + Past Simple, S + would + V.1
Ex. If I were you, I would tell the truth. (ใช้ were กับทุกประธาน)

• แบบที่ 3 (ตรงข้ามกับความจริงในอดีต): If + Past Perfect, S + would have + V.3
Ex. If I had studied harder, I would have passed the exam.

3. คำศัพท์ตำรวจที่ต้องรู้ (Police Vocabulary)

• Suspect (n.): ผู้ต้องสงสัย

• Victim (n.): เหยื่อ, ผู้เคราะห์ร้าย

• Witness (n.): พยาน (ผู้เห็นเหตุการณ์)

• Arrest (v.): จับกุม

• Evidence (n.): หลักฐาน (เป็นนามนับไม่ได้)

• Investigate (v.): สืบสวน, สอบสวน
