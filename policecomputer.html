สรุปเนื้อหาคอมพิวเตอร์เบื้องต้น

1. ฮาร์ดแวร์ (Hardware) และซอฟต์แวร์ (Software)

• CPU (Central Processing Unit): หน่วยประมวลผลกลาง เปรียบเสมือนสมองของคอมพิวเตอร์ มีหน้าที่คำนวณและประมวลผลคำสั่ง

• RAM (Random Access Memory): หน่วยความจำหลักแบบชั่วคราว ข้อมูลจะหายไปเมื่อปิดเครื่อง (Volatile Memory)

• ROM (Read Only Memory): หน่วยความจำหลักแบบถาวร อ่านได้อย่างเดียว ข้อมูลไม่หายเมื่อไฟดับ มักเก็บ BIOS

• หน่วยความจุ: 1 Byte = 8 bits, 1 KB = 1024 Bytes, 1 MB = 1024 KB, 1 GB = 1024 MB

• Software: แบ่งเป็น 1. ซอฟต์แวร์ระบบ (OS เช่น Windows, Linux, iOS) 2. ซอฟต์แวร์ประยุกต์ (โปรแกรมใช้งาน เช่น Word, Excel, Line)

2. ระบบเครือข่ายและอินเทอร์เน็ต (Network & Internet)

• LAN (Local Area Network): เครือข่ายระยะใกล้ เช่น ภายในตึก ห้องเรียนสำนักงานเดียวกัน

• WAN (Wide Area Network): เครือข่ายระยะไกลระดับประเทศหรือทั่วโลก (อินเทอร์เน็ตคือ WAN ชนิดหนึ่ง)

• IP Address: หมายเลขประจำเครื่องคอมพิวเตอร์ในระบบเครือข่าย เปรียบเสมือนบ้านเลขที่

• DNS (Domain Name System): ระบบแปลงชื่อเว็บไซต์ (Domain) ให้เป็น IP Address เพื่อให้มนุษย์จำง่ายขึ้น

• HTTP vs HTTPS: HTTPS มีตัว 'S' (Secure) หมายถึงมีการเข้ารหัสข้อมูล ปลอดภัยกว่า HTTP ธรรมดา

3. โปรแกรมสำนักงานและความปลอดภัยทางไซเบอร์

• MS Word: นามสกุล .docx | คีย์ลัด: Ctrl+C (Copy), Ctrl+V (Paste), Ctrl+Z (Undo), Ctrl+P (Print)

• MS Excel: นามสกุล .xlsx | ฟังก์ชัน: SUM (หาผลรวม), AVERAGE (หาค่าเฉลี่ย), MAX (ค่าสูงสุด), MIN (ค่าต่ำสุด)

• Malware: คำเรียกซอฟต์แวร์ประสงค์ร้ายทุกชนิด (ไวรัส, โทรจัน, สปายแวร์)

• Phishing: การหลอกลวงทางอินเทอร์เน็ต มักส่งลิงก์ปลอมให้กรอกรหัสผ่านหรือข้อมูลบัตรเครดิต

• Ransomware (มัลแวร์เรียกค่าไถ่): ไวรัสที่ทำการเข้ารหัสไฟล์ในเครื่อง แล้วเรียกร้องเงินเพื่อปลดล็อค
